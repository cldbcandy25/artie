# artie

เว็บจดบันทึกรายจ่ายและ Shopping list เวลาไปงาน art market
ไฟล์เดียว ไม่ต้องติดตั้งหรือ build ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง (localStorage)

## ขึ้นเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `artie`)
2. อัปโหลดไฟล์ `index.html`, `README.md` และ `.nojekyll` ไว้ที่หน้าแรกของ repository
3. ไปที่ Settings > Pages
4. ตรง Source เลือก "Deploy from a branch" แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้นกด Save
5. รอประมาณ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/artie/`

## หมายเหตุ
- ข้อมูลไม่ซิงค์ข้ามเครื่อง และจะหายถ้าล้างข้อมูลเบราว์เซอร์
- แก้ไขได้ที่ไฟล์ `index.html` ไฟล์เดียว
